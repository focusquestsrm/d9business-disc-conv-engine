# Product scope

## Release 0 assessment

This repository was empty when the project began and was initialized with Vite + React + TypeScript. The first implementation work focused on consolidating the technical foundation, project documentation, and a working Release 1 application shell with D9Network design direction.

## Release 1 foundation

The MVP foundation establishes:

- D9Network application shell with compact navigation and operational dashboard layout
- Staff dashboard with a metric summary and operational queues
- Quick prospect intake form to capture minimum intake fields
- Campaign workspace and prospect review table
- Local state and mock data structure that mirrors the planned lifecycle and role boundaries
- Test coverage and build validation for the initial user flows

## Out-of-scope for this release

- Real authentication and Supabase integration
- Database-backed RLS and production role enforcement
- Automated outreach or social messaging
- Marketplace and membership conversion workflows
- Public questionnaire and D9 verification review flows

## Release backlog

- Release 1: foundation, authentication shell, intake, campaign management, mock data
- Release 2: routing, workflows, verification, consent ledger, outreach queue
- Release 3: profile claims, marketplace, membership and spotlight flows
- Release 4: reports, revenue attribution, executive intelligence, hardening
